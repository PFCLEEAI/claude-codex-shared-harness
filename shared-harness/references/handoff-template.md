# Handoff Template

Use this structure for implementation, review, or test lane results:

```md
# <Lane> Handoff: Shared Harness

## Outcome

- shipped | blocked | needs follow-up

## Changed Paths

- `/absolute/path`

## Checks Run

- `<command>`: pass | fail | not run

## Risks

- `<risk or none>`

## Next Steps

- `<next action or none>`
```
